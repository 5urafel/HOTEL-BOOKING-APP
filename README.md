# 🏨 Hotel Booking & Reservation Management System

An intuitive, responsive hotel booking web application featuring a customer search interface and a dedicated hotel owner portal for property management.

## 📌 Features

### 🧳 Customer Booking Experience
* **Destination Search & Date Picker:** Search available hotels by destination city with check-in and check-out date selection.
* **Room Listings & Details:** View room options complete with star ratings, image galleries, and amenity breakdowns.
* **Exclusive Offers & Testimonials:** Highlighted promotional offers and customer review sections.

### 👔 Hotel Owner Portal
* **Performance Analytics Dashboard:** View overall business metrics including total revenue generated and total bookings.
* **Recent Booking Activity:** Real-time table view of recent customer bookings and payment details.
* **Inventory Management:** Dedicated sections to register new hotel rooms and update room listings.

---

## 🛠️ Tech Stack

* **Framework:** React 19, Vite
* **Styling:** Tailwind CSS v4
* **Icons & UI Utilities:** React Icons, Custom SVG Assets
